# PodoTurnos

Aplicacion web interactiva para reservar turnos de podologia con Laura Klaraoglan.

## Funcionalidades

- Consulta de tratamientos y precios.
- Seleccion de fecha y horario disponible.
- Formulario con datos del paciente.
- Pago simulado con tarjeta, transferencia o efectivo.
- Confirmacion visual con SweetAlert2.
- Persistencia de turnos con `localStorage`.
- Consulta y cancelacion de reservas.

## Tecnologias

- HTML5
- CSS3 responsive
- JavaScript
- JSON y Fetch API
- SweetAlert2
- LocalStorage

## Como ejecutar

Abrir el proyecto con un servidor local, por ejemplo la extension Live Server de VS Code. Esto es necesario para que `fetch` pueda cargar `data/servicios.json`.
